# Установка Telegram Business NFT Gift DEMO V5 — простые шаги

## GitHub

1. Распакуй **полный ZIP V5**.
2. Создай репозиторий GitHub и загрузи **содержимое** распакованной папки в **корень** репозитория (`Add file` → `Upload files` → `Commit changes`).
3. Проверь: `Dockerfile`, `railway.json`, `requirements.txt` и `alembic.ini` в корне, **не** внутри второй папки.
4. Проверь файлы с расширением: `app/db.py`, `app/main.py`, `app/handlers.py`, `app/telegram.py`, `alembic/versions/0005_faq_text.py`. Изображение: `app/assets/fallback.png`.
5. Не загружай в GitHub токен, пароль, `RAILWAY_VARIABLES_NEW_PROJECT.txt` или настоящий `.env`.

## Railway

1. Создай Railway-проект, подключи GitHub-репозиторий как сервис бота, добавь **PostgreSQL**.
2. У сервиса бота открой **Settings → Networking → Generate Domain**. Выставь **порт 8080**.
3. Открой **Variables сервиса бота** (не PostgreSQL). Добавь:

   - `BOT_TOKEN` — BotFather API Token.
   - `DATABASE_URL` — `${{Postgres.DATABASE_URL}}` (если база называется `Postgres`).
   - `ADMIN_IDS` — **числовой ID** владельца Telegram, например `123456789`.
   - `OWNER_IDS` — тот же ID.
   - `WEBHOOK_URL` — **`https://` + точный публичный домен Railway**, например `https://my-bot.up.railway.app`.
   - `WEBHOOK_SECRET` — секретная случайная строка длиной хотя бы 24 символа, например сгенерировать `python -c "import secrets; print(secrets.token_urlsafe(36))"`.
   - `PORT=8080`, `DEFAULT_IMAGE_PATH=app/assets/fallback.png`, `DEFAULT_STARS=1000`, `DEFAULT_EXPIRATION=30`, `LOG_LEVEL=INFO`.

4. Сохрани изменения и нажми **Deploy / Apply Changes**. На стартовых логах должны быть `telegram_authorized` и `service_ready`.
5. Открой `https://ТВОЙ-ДОМЕН/health`: ожидается `{"status":"ok"}`.
6. В BotFather для бота включи **Business / Secretary Mode** и **`/setinline`**. Для inline плейсхолдер можно указать `NFT-ссылка 1000 15м`.
7. В своём Telegram Business подключи бота с правами `can_reply`; для удаления отправленных вручную команд после отправки замены потребуется `can_delete_all_messages`. Права выбирает владелец, не бот.
8. В личном чате бота напиши `/start`, затем `/test`. Проверь карточку и кнопки.
9. В доступном Business-чате после входящего сообщения другого человека отправь:

   ```text
   https://t.me/nft/PlushPepe-123
   1000
   15м
   ```

   Бот попробует **отредактировать твою команду** в карточку. Если Telegram не разрешает — создаст новую карточку и, если права позволяют, удалит команду. Если фото не найдено, попробуй приложить фото NFT с тремя строками в подписи. Никогда не указывай изображение другого NFT.
10. В любом другом открытом чате набери `@твой_бот https://t.me/nft/PlushPepe-123 1000 15м` и **выбери** inline-результат. Это не отправка напрямую ботом на чужой username.

## Если не работает

- Бот пишет `ADMIN_ID=не задан` или логи `aiogram.dispatcher:Start polling`: запущен **другой проект**, не этот V4. Проверь **Railway → Settings → Source** и отключи старый процесс с тем же токеном.
- `WEBHOOK_URL должен быть публичным HTTPS-URL`: обязательно ставь **`https://`** в начале.
- `ModuleNotFoundError app.db`: файл `app/db.py` отсутствует или загружен под именем `db` без `.py`.
- `DEFAULT_IMAGE_PATH`: нужна папка `app/assets/` и реальный файл `fallback.png`.
- `DATABASE_URL`: нужен полный Postgres URL или референс `${{Postgres.DATABASE_URL}}`.
- `/health` не открывается: проверь Public Networking и порт `8080`.
- `/start` молчит: проверь `Deploy Logs`, `Webhook_URL` и что **тот же токен не используется ещё одним сервером**.
- `/test` работает, но Business-чат не работает: проверь Business подключение, `can_reply`, доступ к этому чату и входящее сообщение собеседника за последние 24 часа. Для удаления требуется `can_delete_all_messages`.
- Нет офера в любом чате: проверь `/setinline` у BotFather; **нужно выбрать результат inline**, не просто отправить строку `@бот ...` как текст.
- Изображение недоступно: сервис Fragment может не выдавать конкретный NFT; приложи свою фотографию в Business-чате или используй текстовый inline-результат.
- Новая карточка есть, старая команда осталась: редактирование отвергнуто, и у бота нет права удаления. Это ожидаемое безопасное поведение, не ошибка отправки.

**DEMO:** бот не перечисляет Stars и не переводит NFT. В карточках и кнопках это явно указано. Подпись **«Бот от A/X T’eams»** остаётся только в личном интерфейсе бота.

Для обновления **V4** загрузи V5-патч в корень GitHub (совпадающие пути должны замениться). Миграция `0005_faq_text` применится автоматически. PostgreSQL удалять не нужно. Если у тебя V3 или неизвестная версия — лучше использовать полный архив V5.

Основная кнопка теперь **«🧪 Тест офера»**: она не требует Business. Для отправки в обычный чат используй **«📤 В любой чат»** и inline после `/setinline` в @BotFather. FAQ и username поддержки: `/admin` → «✏️ FAQ» / «👤 Контакт поддержки». В Business-чате можно отправить явный тестовый триггер `#тестофер` — только от владельца подключения и при разрешённых условиях.
