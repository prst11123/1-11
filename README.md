# Telegram NFT Gift Offer — DEMO V7

**DEMO: это не официальная платёжная оферта Telegram. Никаких реальных Stars, оплат и передач NFT.** Все публичные карточки имеют пометку DEMO. Подпись «Бот от A/X T’eams» видна только в личном чате бота, не в оферах.

## Тест без Business

В личном чате бота нажмите **«🧪 Тест офера»** или `/test`. Бот отправит карточку с фото-заглушкой и ровно двумя кнопками: **«✕ Отклонить»** и **«✓ Принять»**. После принятия остаются явно демонстрационный результат, справка о DEMO и настроенный контакт поддержки. Для этого **не нужен Business Connection**, получатель и ответ от другого аккаунта. В отдельном сообщении под карточкой есть кнопка **«📤 Отправить DEMO в другой чат»**: она запускает выбор чата в inline-режиме (включите `/setinline` в BotFather).

Создатель офера должен быть администратором или пользователем из whitelist. Получателю не требуется `/start` или доступ к созданию оферов. `/faq` доступна и без whitelist; блокировка аккаунта сохраняет силу.

В нижнем меню больше нет кнопки «Создать офер» — она заменена на «🧪 Тест офера». Старый мастер оставлен под `/create` для совместимости, он по-прежнему использует Telegram Business и известные чаты.

## Отправка в обычный чат, даже если собеседник не писал боту

1. В BotFather выберите бота и включите `/setinline` (например, placeholder `NFT ссылка Stars минуты`).
2. На своём основном аккаунте откройте любой **обычный чат, в котором вы сами вправе писать** (включая чат со вторым тестовым аккаунтом).
3. Наберите `@имя_бота` и **пробел**. Сразу появится тестовый DEMO-офер. **Выберите результат**, чтобы Telegram опубликовал карточку в этом чате.
4. Для собственного URL наберите `@имя_бота https://t.me/nft/PlushPepe-123 1000 15м`, выберите текстовую карточку (или фото, если публичное изображение доступно).
5. Второй аккаунт нажимает «Принять», «Отклонить» и другие DEMO-кнопки. Результат отображается в той же карточке.

**Ограничение Telegram:** бот не может незаметно читать и заменять абсолютно любое ваше сообщение во всех личных чатах, куда он не подключён. Он не может сам писать пользователям, которые ему не открывали диалог, просто по username. Inline-режим — официальный способ опубликовать карточку **от вашего аккаунта** в таком чате через явный выбор результата.

## Отправка в Telegram Business (при подключении)

В доступном частном Business-чате от лица владельца отправьте **одно сообщение**:

```
https://t.me/nft/PlushPepe-123
1000
15м
```

Или отправьте **`#тестофер`** — для него используется тестовое фото из проекта (не зависит от источника NFT). Обрабатываются только команды владельца подключения с разрешениями на этот чат; чужие обычные сообщения не трогаются. Упоминание `@бота` для Business-команды не требуется.

Для текстовой команды бот отправляет отдельную фотокарточку, сохраняя исходное сообщение. Для фото с командой в подписи он редактирует подпись. Необязательный `BUSINESS_EDIT_TEXT=true` возвращает попытку преобразования текстовой команды в фото. При явном отказе редактирования возможна отдельная карточка; при тайм-ауте или ограничении Telegram повторной отправки нет. Доступность чата и возможность ответа зависят от разрешений Telegram Business и недавнего входящего сообщения собеседника.

При `PEER_FLOOD` отправку ограничил Telegram. Проверьте аккаунт через официальный [@SpamBot](https://t.me/SpamBot) и повторите после снятия ограничения. Приложение не обходит ограничения другими методами и не повторяет отправку автоматически. При неоднозначном ответе API сначала осмотрите чат: карточка могла появиться, хотя бот не получил подтверждение.

## FAQ и поддержка, редактируются администратором

Кнопка **«❓ FAQ»** (или `/faq`) показывает ошибки, советы по настройке и username поддержки. Администратор открывает `/admin` → **«✏️ FAQ»** и может изменить весь текст, сбросить его; через **«👤 Контакт поддержки»** может поменять `@username`. Данные сохраняются в PostgreSQL и переживают перезапуск бота. Формат FAQ — обычный текст, 30–3000 символов (HTML экранируется). Контакт также показывается в новых результатах принятия DEMO. Переход в меню или `/cancel` завершает режим редактирования.

## Диагностика и запуск

`/diag` доступна администраторам, показывает текущий Webhook, ошибки Telegram и информацию о Business-подключениях. Подробности по GitHub/Railway — в `DEPLOY_RU.md`, ручной сценарий проверки — в `SMOKE_TEST_RU.md`.

Технически: Python 3.12, aiohttp (webhook), PostgreSQL, SQLAlchemy, Alembic, официальный Bot API. Миграции выполняются при запуске контейнера; необходима `0006_guest_bindings.py` для привязки Guest-карточек и повторных обновлений. Старые данные сохраняются. С подтверждения владельца V7 опубликована в ветке `audited-v7-fixes-20261107` репозитория `prst11123/1-11`; существующий Railway-сервис подключён к этой ветке. Настройки Guest/Inline включаются владельцем бота в BotFather, независимо от развёртывания кода.


## V6: экран после «Принять» (DEMO)

После принятия фотокарточка **сохраняет изображение NFT** и показывает статус тестового принятия, пояснение об отсутствии настоящей продажи и контакт поддержки. В текстовых карточках отображение предпросмотра конкретного NFT зависит от Telegram и не гарантируется. Username берётся из `Админ-панель → Контакт поддержки` (`DEMO_CONTACT_USERNAME` — только значение по умолчанию). После изменения контакта он применяется к **новым** обработанным нажатиям; ранее отправленные карточки Telegram автоматически не переоформляются.

После принятия доступны «ℹ️ Что означает DEMO?» и, если контакт настроен, «🆘 Поддержка». Передавать NFT для получения Stars **не нужно**: приложение не осуществляет сделок и не обещает выплат.

Чтобы проверить без Business: `/test` → «✓ Принять» → проверить подпись и поддержку. Отправка в другие чаты: inline через `@имя_бота`.

## V7: отправка без inline-поиска через Guest Mode

В поддерживаемом обычном чате отправь `@your_bot https://t.me/nft/InputKey-25057 1900 15` прямо в переписке, заменив username на своего бота. Guest Bot ответит отдельной DEMO-карточкой с двумя кнопками. Подключение Business и запуск бота получателем не требуются. Включи Guest Mode в Mini App @BotFather. Предпросмотр конкретной NFT-ссылки зависит от Telegram; при отказе API возможна карточка без изображения. Если Guest Mode недоступен, используй inline с явным выбором результата. Подробно: [GUEST_MODE_RU.md](GUEST_MODE_RU.md).

Бот не скрывает своё происхождение и не заменяет произвольное сообщение. Действия кнопок демонстрационные; NFT и Stars не перемещаются.
