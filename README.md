# Telegram NFT Gift Offer — DEMO V5

**DEMO: это не официальная платёжная оферта Telegram. Никаких реальных Stars, оплат и передач NFT.** Все публичные карточки имеют пометку DEMO. Подпись «Бот от A/X T’eams» видна только в личном чате бота, не в оферах.

## Главное изменение V5: тест без Business

В личном чате бота нажмите **«🧪 Тест офера»** или `/test`. Бот отправит карточку с фото-заглушкой и кнопками «Принять», «Отклонить», затем «Передать (DEMO)» и «Как передать?». Для этого **не нужен Business Connection**, получатель и ответ от другого аккаунта. В тестовой карточке есть кнопка **«📤 Отправить DEMO в другой чат»**: она запускает выбор чата в inline-режиме (включите `/setinline` в BotFather).

В нижнем меню больше нет кнопки «Создать офер» — она заменена на «🧪 Тест офера». Старый мастер оставлен под `/create` для совместимости, он по-прежнему использует Telegram Business и известные чаты.

## Отправка в обычный чат, даже если собеседник не писал боту

1. В BotFather выберите бота и включите `/setinline` (например, placeholder `NFT ссылка Stars минуты`).
2. На своём основном аккаунте откройте любой **обычный чат, в котором вы сами вправе писать** (включая чат со вторым тестовым аккаунтом).
3. Наберите `@имя_бота` и **пробел**. Сразу появится тестовый DEMO-офер. **Выберите результат**, чтобы Telegram опубликовал карточку в этом чате.
4. Для собственного URL наберите `@имя_бота https://t.me/nft/PlushPepe-123 1000 15м`, выберите текстовую карточку (или фото, если публичное изображение доступно).
5. Второй аккаунт нажимает «Принять», «Отклонить» и другие DEMO-кнопки. Результат отображается в той же карточке.

**Ограничение Telegram:** бот не может незаметно читать и заменять абсолютно любое ваше сообщение во всех личных чатах, куда он не подключён. Он не может сам писать пользователям, которые ему не открывали диалог, просто по username. Inline-режим — официальный способ опубликовать карточку **от вашего аккаунта** в таком чате через явный выбор результата.

## Отправка в Telegram Business (при подключении)

В доступном частном Business-чате от лица владельца отправьте **одно сообщение**:

```
https://t.me/nft/PlushPepe-123
1000
15м
```

Или отправьте **`#тестофер`** — для него используется тестовое фото из проекта (не зависит от источника NFT), чтобы проверить редактирование исходного Business-сообщения. Обрабатываются только команды владельца подключения с разрешениями на этот чат; чужие обычные сообщения не трогаются.

Бот **пытается** заменить исходную команду карточкой. При явном отказе редактирования он отправит отдельную карточку, а исходную команду удалит только с разрешением Telegram. Доступность чата и возможность ответа зависят от разрешений Telegram Business и недавнего входящего сообщения собеседника. Автоматической отправки любому человеку в обход ограничений нет.

## FAQ и поддержка, редактируются администратором

У всех пользователей есть кнопка **«❓ FAQ»** (или `/faq`). Она показывает ошибки, советы по настройке и username поддержки. Администратор открывает `/admin` → **«✏️ FAQ»** и может изменить весь текст, сбросить его; через **«👤 Контакт поддержки»** может поменять `@username`. Данные сохраняются в PostgreSQL и переживают перезапуск бота. Формат FAQ — обычный текст, 30–3000 символов (HTML экранируется); поддержка указана только внутри самого бота.

## Диагностика и запуск

`/diag` доступна администраторам, показывает текущий Webhook, ошибки Telegram и информацию о Business-подключениях. Подробности по GitHub/Railway — в `DEPLOY_RU.md`, ручной сценарий проверки — в `SMOKE_TEST_RU.md`.

Технически: Python 3.12, aiohttp (webhook), PostgreSQL, SQLAlchemy, Alembic, официальный Bot API. Миграции выполняются при запуске контейнера; V5 добавляет `0005_faq_text.py`. Старые данные сохраняются.


## V6: экран после «Принять» (DEMO)

В этом обновлении карточка после принятия **сохраняет изображение NFT** и вместо кнопок передачи показывает статус тестового принятия, пояснение об отсутствии настоящей продажи и контакт поддержки. Username берётся из `Админ-панель → Контакт поддержки` (`DEMO_CONTACT_USERNAME` — только значение по умолчанию). После изменения контакта он применяется к **новым** обработанным нажатиям; ранее отправленные карточки Telegram автоматически не переоформляются.

После принятия доступны «ℹ️ Что означает DEMO?» и, если контакт настроен, «🆘 Поддержка». Передавать NFT для получения Stars **не нужно**: приложение не осуществляет сделок и не обещает выплат.

Чтобы проверить без Business: `/test` → «✓ Принять» → проверить подпись и поддержку. Отправка в другие чаты: inline через `@имя_бота`.
